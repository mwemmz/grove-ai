1 · Input and splitting Daily temperature files are split, and each split goes to its own mapper.
2 · Map Each mapper turns its lines into key/value pairs: <city, temperature>.
3 · Shuffle and sort All pairs with the same city go to the same reducer.
4 · Reduce Each reducer keeps the highest value: Lusaka 38, Harare 27, Cape Town 33, Windhoek 32.
5 · Spark instead MapReduce writes to disk between steps. Spark keeps data in memory and rebuilds lost pieces from their lineage, so repeated jobs run much faster.
