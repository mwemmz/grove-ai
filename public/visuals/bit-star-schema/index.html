1 · The fact table At the centre: one row per sale, with the measures you add up (quantity, amount) and a key for each dimension.
2 · Dimension tables Around it: the who, what, where and when. Customer, product, store, date.
3 · A star Each key in the fact table points to one dimension. Fact in the middle, dimensions around it: a star.
4 · A query “Total sales by province in Q1” joins the fact table to store and date, then adds up amount.
5 · Snowflake Split a dimension further (product → category) to cut repetition. Fewer duplicates, but more joins.
