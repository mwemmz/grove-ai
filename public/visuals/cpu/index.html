1 · Fetch The Program Counter holds the address of the next instruction. It is sent to memory.
2 · Memory answers RAM looks up that address and sends the instruction back to the CPU.
3 · Decode The Control Unit reads the instruction: ADD means "use the ALU".
4 · Execute The registers feed 2 and 3 to the ALU, which adds them.
5 · Write back The result goes into a register and the Program Counter moves to 0x03.
