1 · Push A stack adds items on top. Push A, then B, then C.
2 · Pop Pop removes the newest item. C was last in, so C is first out.
3 · Enqueue A queue adds items at the back. Enqueue A, then B, then C.
4 · Dequeue Dequeue removes the oldest item. A was first in, so A is first out.
5 · Compare Same items, opposite order: stack is last in first out, queue is first in first out.
