1 · Fetch The Program Counter holds the address of the next instruction. It passes that address to memory.
2 · Memory answers RAM looks up that address and sends the instruction back to the CPU.
3 · Decode The Control Unit reads the instruction and works out what to do: ADD means "use the ALU".
4 · Execute The ALU does the sum. Values 2 and 3 come in from the registers.
5 · Write back The result goes into a register, and the Program Counter moves on to the next instruction.
