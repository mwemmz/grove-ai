1 · Extract Copy data out of the systems that run the business: tills, mobile money, the customer database.
2 · Transform Clean it in a staging area: remove duplicates, fix formats, match IDs, add up where needed.
3 · Load Write the clean rows into the warehouse’s fact and dimension tables.
4 · Use it Reports, dashboards and KPIs now read one consistent copy of the truth.
5 · ETL vs ELT ELT loads the raw data first and transforms it inside the warehouse. Common with cloud warehouses.
