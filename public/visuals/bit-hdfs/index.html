1 · Split into blocks A 384 MB file is cut into 128 MB blocks: B1, B2, B3.
2 · Replicate Each block is copied to three different DataNodes (replication factor 3).
3 · The NameNode keeps the map The NameNode stores only metadata: which blocks make the file, and where each copy lives.
4 · A DataNode fails DN2 stops sending heartbeats. Every block it held still has two other copies, so reads carry on.
5 · Self-healing The NameNode copies the missing blocks to healthy nodes until each block has three copies again.
